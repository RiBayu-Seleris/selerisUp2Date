# Distribution status

Distribution of Seleris rPPG Flutter Care SDK Profile A is authorized by the project owner as of 25 August 2026.

The confidential legal basis is intentionally not reproduced in this technical package. Recipients must distribute the SDK and Web example only through channels authorized by the project owner and must retain all third-party notices, privacy disclosures, and experimental-measurement labels.

The official Flutter-team handoff is the versioned SDK library ZIP. The host
team extracts it as a path dependency and builds its own application. The
example source and compiled Web output are integration references and are not
the Selica production application. Product teams remain responsible for host
identity, HTTPS/security headers, consent, retention policy, and compliance
review.
